# Restricciones

| ID | Restricción | Descripción |
|---|---|---|
| RC01 | Aplicación web | El sistema debe desarrollarse como una aplicación accesible mediante un navegador web. |
| RC02 | Control de versiones | El código fuente debe gestionarse utilizando Git y mantenerse en un repositorio compartido. |
| RC03 | API REST | La comunicación entre el frontend y los servicios del sistema debe realizarse mediante una API REST. |
| RC04 | Pasarela de pago | El sistema debe integrarse con una pasarela de pago externa para procesar las operaciones de pago. |
| RC05 | Servicio de envío | El sistema debe integrarse con un servicio externo de envío para gestionar la entrega de pedidos. |
| RC06 | Integración con ERP | El sistema debe integrarse con el ERP existente de la empresa para obtener productos y stock. |
| RC07 | Facturación electrónica | El sistema debe emitir comprobantes de pago mediante un servicio de facturación externo. |
| RC08 | Tiempo del proyecto | El primer entregable de arquitectura debe completarse dentro del semestre académico. |
